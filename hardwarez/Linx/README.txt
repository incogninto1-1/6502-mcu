Say hello to the codename Linx. (not ready yet)

This is a 6502 computer that I want to make for real bare-metal nerds like me and maybe you.
I was inspired somewhat by the Apple 2 and the Commodore 64. Neither of which I own because:

	1) I didn't grow up in the 8 bit era so I didn't have any 8 bit computer growing up. I only had x86 and ARM based machines.
	2) They're insanely expensive nowadays. I get it that they're rare and collectible n stuff, but I reeeeally want a computer that I can interact with bare-metal without the requirement of a complex OS that takes a long time to start up

There is also the Commander X16, I know, but it is also p expensive as well and has some p overkill components for me to get started like a costly FPGA based graphics chip (VERA). Not to hate on the X16 because it is a genuinely great machine. I just want to make a cheap solution for my applications.

So what COULD Project Linx bring to the table? (still thinking about it)

A 6502 CPU
16 KB of flat RAM (not banked)
Possibly additional RAM (banked)
A framebuffer connected to an RCA jack
Parallel bus for external peripherals
The possibility to connect an external IDE HDD (very hard but maybe)
an on-board ATMega 16 microcontroller (possibly. this could be used for offloading some heavy tasks to it for faster execution)
PS/2 keyboard and mouse support
